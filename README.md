## 🧰 技术栈说明

本项目为**零依赖纯前端静态应用**，不引入任何前端框架、构建工具或外部 CDN，双击 `index.html` 即可离线运行。

### 前端基础

- **HTML5**：语义化标签、内联 SVG（桥梁仿真骨架与导航图标）、`<canvas>` 图表容器。
- **CSS3**：CSS 自定义属性（`css/base.css` 中的设计令牌）、Grid / Flexbox 布局、媒体查询响应式、渐变 / 圆角 / 阴影 / `backdrop-filter` 等。
- **JavaScript (ES6+)**：原生 `class` 模块化组织、模板字符串渲染、`setInterval` 驱动的实时数据流。

### 自研能力（零第三方依赖）

- **Canvas 工业图表引擎**（`js/charts.js`）：时程波形曲线、双柱索力对比、五维健康雷达图、仪表盘，支持 Retina 高清自适应与阈值警戒线。
- **SVG 桥梁数字孪生仿真**（`js/dashboard.js`）：动态生成斜拉桥立面骨架、测点热点脉冲与悬浮详情。
- **本地模拟数据层**（`js/mock-data.js`）：223 个设备、11 类监测项、5 个工程案例的仿真数据。

### 工程组织

- **样式**：按模块拆分 `base / dashboard / portal / workorder / ai` 五个 CSS 文件。
- **脚本**：`app.js` 全局路由与 12 个页面切换；`dashboard / portal / workorder / ai` 四大业务控制器；`charts.js` 图表库；`mock-data.js` 数据源。
- **资源**：`assets/img` 内从 PDF 提取的工程实图与图表，全部本地引用、离线可用。

### 运行与部署

- **运行**：双击 `index.html`（`file://` 协议离线运行），或 `python -m http.server` 本地预览。
- **部署**：任意静态文件托管、GitHub Pages、Nginx 等，无需构建步骤。
- **版本管理**：Git（`main` 分支），本地提交 + GitHub 远程仓库。
- **兼容性**：现代浏览器（Chrome / Edge / Firefox / Safari），需支持 ES6 与 CSS Grid。
